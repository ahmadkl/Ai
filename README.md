# ستوري ستوديو (Story Studio)

تطبيق أندرويد يحوّل القصة المكتوبة إلى فيديو أنيميشن: لوحة قصصية، شخصيات ثابتة الشكل، صور، تعليق صوتي، ترجمة، موسيقى، حركة كاميرا، وتصدير MP4.

## الحصول على APK (بدون تثبيت أي شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع **كل محتويات هذا المجلد** (بما فيها المجلد المخفي `.github`).
2. افتح تبويب **Actions** ← **Build APK** ← **Run workflow** (يعمل تلقائيًا عند كل رفع).
3. بعد دقائق نزّل `StoryStudio-APK` من أسفل صفحة التشغيل، وفيه `app-debug.apk`. ثبّته على هاتفك.

## تجربته كموقع
ارفع مجلد `www` على GitHub Pages أو افتحه بأي خادم ثابت.

## مصادر الذكاء الاصطناعي (من تبويب الإعدادات)
- **مجاني بلا مفتاح (الافتراضي):** Pollinations للقصة والصور والصوت. أبطأ وأقل ثباتًا، وقد يتأخر أحيانًا.
- **Google Gemini (مفتاح من aistudio.google.com):** نص وصور، ويدعم الصور المرجعية لثبات الشخصيات.
- **OpenAI أو أي خادم متوافق:** نص وصور وصوت.
- **fal.ai (اختياري):** تحويل كل صورة إلى مقطع فيديو حقيقي. بدونه يستخدم التطبيق حركة كاميرا على الصور.

## ملاحظات
- التصدير يتم بالزمن الحقيقي: فيديو مدته دقيقة يحتاج دقيقة تصدير. أبقِ الشاشة مفتوحة أثناءه.
- كل المشاريع تُحفظ على جهازك فقط.
